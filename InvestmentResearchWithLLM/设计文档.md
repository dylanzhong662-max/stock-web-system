# 行业投研助手 — 设计文档

> 版本 v0.1 | 2026-04-26

---

## 一、项目定位

基于大模型（DeepSeek R1 + 联网搜索）的**行业投研助手**，参照机构研究员的分析框架，自动输出：

- 行业产业链图谱（分层 / 玩家 / 利润池 / 竞争强度 / 投资判断）
- 单公司在产业链中的定位与财务快照
- 基于持仓（读 holderAndAction 数据库）的个性化研究报告

**端口**：`8002`（holderAndAction 用 8001，finance-analysis 用 8000）

---

## 二、核心分析框架（来自产品图）

每一份行业报告都输出以下结构，对标图中框架：

| 输出维度 | 说明 |
|---------|------|
| 产业链分层 | 层级名称 + 解决的核心问题 |
| 核心玩家 | 美国/全球 + 中国相关玩家 |
| 利润率/议价能力 | 定性评级 + 关键驱动因素 |
| 竞争强度 | 低/中/高 + 护城河说明 |
| 投资判断 | 当前机会/风险 + 12-24 月展望 |
| 利润池排名 | 哪层最赚钱、哪层最容易被卷 |

## 三、系统架构

```
用户输入（Chat UI / REST API）
          ↓
    Orchestrator（意图识别 + 任务路由）
          ↓
  ┌───────────────┬──────────────┬────────────────┐
  │  行业分析      │  公司分析     │  持仓研究       │
  │ ChainAnalyzer │CompanyAnalyzer│PortfolioResearch│
  └───────────────┴──────────────┴────────────────┘
          ↓
    DataFetcher（Tavily 搜索 + yfinance + AKShare）
          ↓
    DeepSeek R1（结构化推理 + 报告生成）
          ↓
    SSE 流式输出 → Chat UI / JSON Response
```

### 意图类型

| 意图 | 示例输入 | 路由到 |
|------|---------|--------|
| `chain` | "分析 AI 算力产业链" | ChainAnalyzer |
| `company` | "分析英伟达" / "NVDA 在哪一层" | CompanyAnalyzer |
| `portfolio` | "我的持仓里哪些值得加仓" | PortfolioResearch |
| `compare` | "比较 NVDA 和 AMD" | CompanyAnalyzer × 2 |
| `qa` | 其他问题 | 通用问答兜底 |

### 5.2 `chain_analyzer.py`

核心模块，输出产业链分析报告。

**输入**：行业名称（如 "AI 算力"、"半导体"、"新能源汽车"）

**处理步骤**：
1. DataFetcher 搜索行业最新动态（Tavily，3-5 条）
2. 拼装 prompt（内置框架 + 实时数据）
3. DeepSeek R1 生成结构化报告
4. 结果缓存到 reports.db（TTL 24 小时）

**输出结构**：
```
## {行业名} 产业链分析

### 产业链全景
| 层级 | 解决的问题 | 美国/全球核心玩家 | 中国相关玩家 | 利润率/议价能力 | 竞争强度 | 投资判断 |

### 利润池排名
| 排名 | 层级 | 利润率判断 | 核心逻辑 |

### 12-24 个月展望
...

### 关键风险
...
```

**支持的初始行业**（AI 产业链优先，模板可扩展）：
- AI 算力全链（完整 8 层）
- 半导体设备/材料
- AI 服务器/网络
- 云计算/IaaS
- AI 应用/SaaS

### 5.3 `company_analyzer.py`

**输入**：公司名称 or ticker（支持 A 股代码）

**处理步骤**：
1. yfinance / AKShare 拉取财务快照（市值 / 毛利率 / P/E / 营收增速）
2. Tavily 搜索最新新闻（近 30 天，3 条）
3. R1 分析：定位产业链哪一层 + 竞争优势 + 投资风险

**输出结构**：
```
## {公司名}（{ticker}）投研快照

### 产业链定位
所在层级 + 在该层的竞争地位（领导者/挑战者/跟随者）

### 财务快照
市值 | 毛利率 | P/E（NTM）| 营收增速（YoY）

### 核心投资逻辑
（3 条 bullet）

### 主要风险
（3 条 bullet）

### 结论
买入/观望/回避 + 核心理由
```

### 5.4 `portfolio_research.py`

**数据源**：读取 `HOLDER_DB_PATH`（holderAndAction 的 `trading.db`），取 positions 表中所有开仓持仓。

**设计思路：自上而下筛选 + 自下而上验证**

两个分析视角天然互补，应串联而非并列：
- **自上而下**（本系统主导）：行业 → 产业链哪层利润最厚 → 该层有哪些核心标的
- **自下而上**（equity-research skill 主导）：某只股票 → 财务质量 → 共识预期差在哪

PortfolioResearch 是两者的交汇点：先用 ChainAnalyzer 确定每个持仓在产业链中的层级与竞争地位，再对每个持仓调用 equity-research skill 的输出格式做深度财务验证，最终综合出加减仓建议。

**处理步骤**：
1. 读出持仓列表（ticker / 成本价 / 当前盈亏）
2. 逐一调用 CompanyAnalyzer 获取产业链定位（所在层级 / 竞争地位）
3. 对每个持仓调用 equity-research 分析流程，补充定量数据：
   - 卖方共识预测（FY1/FY2 EPS、Revenue、EBITDA）及分析师离散度
   - 历史财务趋势（ROE / ROIC / Net Debt/EBITDA，近 3 年）
   - Forward P/E（价格 ÷ 共识 EPS）及与行业均值对比
4. R1 综合分析：哪些持仓产业链定位强且估值合理、哪些定位弱或估值透支、整体组合的产业链层级集中度

**数据可信度原则**：
- Tavily 搜索结果**只用于叙事背景和近期动态**，不作为财务估值计算依据
- 估值锚点（PE/EV/共识）**必须来自 equity-research skill 的结构化数据源**（IBES / yfinance）
- 凡依赖搜索数字的结论，报告中需标注"仅供参考，建议核实"

**输出结构**：
```
## 持仓投研报告

### 组合概览
持仓数量 | 行业分布 | 产业链层级分布（各层持仓占比）

### 逐仓深度分析
每个持仓输出两层视角：

**① 产业链视角**（自上而下）
所在层级 | 竞争地位（领导者/挑战者/跟随者）| 该层利润池评级 | 未来 12-24 月展望

**② 财务估值视角**（自下而上，equity-research 格式）
| 指标 | FY1 共识 | FY2 共识 | 分析师数 | 离散度 |
| EPS / Revenue / EBITDA | ... | ... | ... | ...% |

| 指标 | FY-2 | FY-1 | 当前 | 趋势 |
| 毛利率 / 营业利润率 / ROE / Net Debt/EBITDA | ... |

Forward P/E：X.Xx（vs 行业均值 Y.Yx）

**③ 综合结论**
产业链地位 × 估值合理性 → 加仓 / 持有 / 减仓 + 核心理由一句话

### 组合建议
加仓优先级 / 持有 / 减仓 排序，附产业链集中度风险提示
（如：组合 60% 集中在 AI 算力产业链的硬件层，若 CapEx 周期反转风险较高）
```

## 九、Tavily API 申请（免费额度够用）

Tavily 是专为 AI 应用设计的搜索 API，返回干净的结构化结果（非 HTML）。

**申请步骤**：
1. 打开 https://app.tavily.com/sign-up
2. 用 Google 或邮箱注册
3. 注册后进 Dashboard → API Keys → 复制 `tvly-xxx` 格式的 key
4. 填入 `.env` 的 `TAVILY_API_KEY`

**免费额度**：1,000 次/月（每次行业分析约消耗 3-5 次，够日常使用）

**付费参考**：超出后 $0.005/次，分析一份完整报告约 $0.02，极低。
