## 三种核心用法

### 1. 产业链分析

**适合场景**：研究一个新行业，先搞清楚谁在哪层、哪层最赚钱、中国有哪些玩家。

示例输入：
```
分析 AI 算力产业链
分析半导体设备材料产业链
分析新能源汽车产业链
```

输出包含：
- **产业链全景表**：层级 / 核心玩家（美国+中国）/ 利润率 / 竞争强度 / 投资判断
- **利润池排名**：哪层最赚钱、哪层最容易被卷
- **12-24 个月展望**：需求侧 / 供给侧 / 政策 / 技术拐点
- **关键风险**：3-5 条，注明对哪一层影响最大

> 报告缓存 24 小时，同一行业再次查询秒出。

---

### 2. 公司分析

**适合场景**：找到感兴趣的标的后，快速了解它在产业链哪一层、竞争地位、财务概况、投研结论。

示例输入：
```
分析英伟达
NVDA 的投资逻辑是什么
分析台积电 TSM
比较 NVDA 和 AMD
分析宁德时代 300750
```

输出包含：
- 产业链层级定位 + 竞争地位（领导者/挑战者/跟随者）
- 财务快照（市值 / 毛利率 / PE / 营收增速，来自 yfinance）
- 核心投资逻辑（3 条）
- 主要风险（3 条）
- 结论：买入 / 观望 / 回避

> ⚠️ 财务数据来自 yfinance，适合产业链判断。**如需精确估值和卖方共识预测**，在 Claude CLI 中运行：
> ```
> /equity-research NVDA
> ```
> 该命令会调用 IBES 分析师共识数据（EPS/Revenue/EBITDA FY1/FY2）和历史财务数据库，是本工具财务分析的深度补充。

---

### 3. 持仓研究报告

**适合场景**：定期审视自己的组合，看清每个持仓的产业链逻辑，找出集中度风险，决定加减仓优先级。

输入：
```
分析我的持仓
我的持仓里哪些值得加仓
```

或直接点左侧「💼 持仓研究报告」按钮。

输出包含：
- **组合概览**：持仓数量、行业分布、产业链层级分布
- **逐仓分析**：每个持仓的产业链定位 + 财务快照 + 加/持/减结论
- **组合建议**：加仓优先级排序
- **产业链集中度风险**：当前组合在哪一层过于集中、对应的宏观风险

> 数据来源：自动读取 holderAndAction（8001）的持仓数据库，有开仓持仓即可使用。

## 推荐工作流

```
自上而下：                          自下而上（深度补充）：
行业产业链分析                       /equity-research <ticker>
    ↓                                       ↓
找到利润最厚的层                     IBES 共识预测（分析师数/离散度）
    ↓                                历史财务趋势（ROE/ROIC/杠杆）
该层核心标的公司分析                  Forward P/E vs 行业均值
    ↓                                       ↓
与持仓研究报告交叉验证             判断预期差在哪（consensus wrong?）
```

两个工具互补，不替代：**本工具做产业链定位和中文市场洞察，`/equity-research` 做精确估值和卖方共识分析。**

---

## 注意事项

- **响应时间**：产业链和公司分析约 30-60 秒（DeepSeek R1 有完整推理过程），页面有流式输出，不会白屏
- **报告缓存**：同一行业 24h / 同一公司 6h / 持仓报告 1h 内再次查询直接命中缓存，秒出
- **数据可信度**：财务数字来自 yfinance，叙事判断来自 Tavily 搜索 + R1 推理，报告中标注来源；如需精确数字请核实或用 `/equity-research`
- **A 股支持**：公司分析支持 A 股代码（如 "分析宁德时代 300750"），但数据完整度不如美股
